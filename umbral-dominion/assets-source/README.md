# Painted concept source art (NOT finished character artwork)

New, original, AI-painted concept studies. The mod build crops source atlases to overlay the previous geometric creature/portrait stills and town backdrop.

- `creature-concepts.png`: 7x2 transparent figurine tiles, 144x112 pixels each.
- `hero-portraits.png`: 8 portrait studies, 88x110 each.
- `ebonspire-town.png`: 800x374 town-composite concept painting.

**Known mismatches:** Tier 2 concept sprites look like skeletal warriors rather than Gloom Hound/Dread Hound; tier 3 sprites look like wraiths rather than Veil Archer/Nightstalker. These are **NOT approved character designs**. The 14 creatures repeat one painted still across movement/attack/death animation references; these are not authored animation frames. Map sprites, town overlays, specialty icons and siege art are still provisional. The build remains a development prototype, Windows gameplay untested.

No copyrighted Heroes III files are included. See `ARTWORK_RELEASE_GATE.md` for release acceptance criteria.
