# Illustrated source key poses

Original AI-generated illustration atlases. The sprites are not derived from copyrighted Heroes III artwork.

- `hounds.webp` (1774x887, 4 columns, 2 rows): first row Gloom Hound, second Dread Hound.
- `archers.webp` (1774x887, 4 columns, 2 rows): first row Veil Archer, second Nightstalker.
- Each row contains 4 named poses: **idle, move, attack/shoot, hit**.

Source atlases are split programmatically by `scripts/compile_sprites.py`. Do not treat the generated interpolations as additional illustrated keyframes. Generated action frames (death, defence, turn, etc.) are placeholders when no separate illustrations exist.
